# Presentación del catálogo público

El listado recupera la barra de Store Web. Todos y Disponibles muestran el inventario disponible del catálogo actual. Novedades, Destacados y Promociones quedan visibles sin acción hasta definir sus reglas.

El detalle usa el espaciado de la plantilla, muestra el precio principal por moneda cuando se permite y mantiene la tabla por tienda. WhatsApp usa el número público de empresa. Si falta, el botón queda deshabilitado y se muestra el aviso.
