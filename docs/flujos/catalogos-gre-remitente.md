# Catálogos de guías de remisión

Platform Admin administra cinco catálogos globales. Cada registro permite editar su nombre, orden y estado. Los códigos se conservan para respetar el contrato de emisión y las referencias de guías históricas. Las altas de códigos oficiales se gestionan al actualizar el catálogo de referencia. Las modificaciones quedan registradas en la auditoría de plataforma.

El formulario GRE usa opciones activas y ordenadas. El servidor valida el estado del código en las nuevas emisiones. El destinatario conserva las cuatro opciones que usaba el formulario y el transportista conserva RUC. El transporte admite público y privado, y el peso admite KGM y TNE. Desactivar una opción afecta a todas las empresas. Las guías históricas conservan sus códigos y el Excel puede resolver el nombre de un documento inactivo.

El ubigeo sigue usando los catálogos geográficos existentes.
